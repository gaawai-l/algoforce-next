# 钱包登录需求

2026-09-28 用户明确要求：使用钱包登录，记住登录状态，下次访问无需再输入用户名和密码。

用户已授权立即移除 Basic Auth，并用 RainbowKit 实施钱包登录。线上已先关闭 Basic Auth，钱包版本 `61e9136` 已成功部署并通过外网HTTP验收；详见[发布记录](releases/2026-09-28-wallet-login.md)。

目标体验：首次使用钱包签名证明地址所有权，服务端验证后建立持久登录会话；同一浏览器在会话有效期内直接进入，退出或会话失效后重新签名。公开钱包地址可用于访问白名单，但仅记录地址不能作为登录凭证。应用不保存钱包私钥或助记词。

用户确认使用 Base，按 Base 主网（chain ID `8453`）记录。用户提供的允许登录地址如下；两者均为 EVM 格式公开地址，服务端白名单已写入部署配置，按实际生效版本验收：

- `0x11890834531ad1127863895fa83983bfc6347bb0`
- `0x092b5f11c081b7f607e7dbf0167d5f9267da215e`

实现采用 SIWE、5 分钟一次性挑战与 30 天 HttpOnly/Secure 登录会话；退出撤销服务端会话。RainbowKit 支持浏览器钱包发现；WalletConnect 扫码需另配真实 project ID。设计和执行记录见 [钱包登录计划](WALLET-LOGIN-PLAN.md)。

## Orbit 登录交互（2026-09-28）

开发代号采用 Orbit。登录页面仅轨道图、代号和 Connect Wallet 按钮；RainbowKit 连接后自动请求签名，无需第二次点击 Sign in。Sonner 提示连接/签名/切链拒绝；拒签可用原按钮重试，未授权钱包断开后可重新选择。原有有效会话直接进入。详见[改版计划](ORBIT-LOGIN-PLAN.md)。
