# DeMark 领域术语

记录本专题会话说明中已经明确的领域含义。计算公式与尚未定稿的政策另记于设计讨论文档。

## Language

**Buy Setup / Buy Countdown**：观察下行持续过程的结构，对应潜在向上反转的观察方向。
_Avoid_: 已建立上涨趋势、买入指令

**Sell Setup / Sell Countdown**：观察上行持续过程的结构，对应潜在向下反转的观察方向。
_Avoid_: 已建立下跌趋势、卖出指令

**Setup 9**：连续 Setup 条件完成九次的结构，表示持续运动可能疲劳，不证明反转已经发生。
_Avoid_: 已确认反转

**Qualified 13**：Countdown 的完成候选已满足所选规则版本的资格条件，并具备可追溯证据。它不等于市场已经发生反转。
_Avoid_: 任何显示为 13 的数字、必然反转

**Unqualified 13**：已有足够证据判断某个 13 候选未通过资格条件。
_Avoid_: 未核验的 13

**Unverified 13**：资格证据不足，无法判断显示的 13 是否合格。
_Avoid_: 不合格的 13、默认合格

**TDST**：由特定 Setup 结构产生的价格边界，其含义须结合所选规则的突破与取消政策解释。
_Avoid_: 无来源的通用支撑阻力线

**Risk Level**：关联特定 Qualified 13 的反转论据风险边界，是否仍有效取决于该论据的生命周期与突破政策。
_Avoid_: 自动止损订单、永久有效的价格线

**Strength score**：策略解释层定义的证据强度评分。
_Avoid_: 胜率、反转概率

**市场 Phase**：描述市场在较长周期中的阶段背景；本专题区分成本关系六态、综合周期指数和首页五档观点，不默认它们具有一一映射。
_Avoid_: Setup/Countdown 计数阶段、施工阶段

**DeMark Regime**：结合原始 DeMark 结构与市场背景形成的策略解释状态；朋友页面的三个中文标签属于这一层。
_Avoid_: DeMark 官方统一三态、原始计数值
