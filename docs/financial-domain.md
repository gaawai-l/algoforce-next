# 金融领域规则

适用于券商接入、记账、导入、风险计算，以及指标的实现和展示。项目范围与只读边界见根目录 [AGENTS.md](../AGENTS.md)。这些规则从原根文件迁入，属于项目约束，不表示相关集成已经实现。

## 券商接入与数据

- 新加坡实体使用 `SecurityFirm.FUTUSG`，与交易市场无关；实际账户按 `acc_id` 选择。`REAL` 表示真实账户数据，不是交易授权。
- 优先使用官方 moomoo OpenD 和 SDK 查询接口。用户在官方 OpenD 登录，本地读取器连接 loopback gateway；登录凭据不进入应用、聊天、仓库或日志。只读流程不索取或保存交易密码。
- 账户采集与 UI、分析分离。社区 MCP 是可选项，采用前检查写入工具、自动解锁行为与账户地区假设。
- 订单、成交、持仓、现金流、费用分别建模：订单不是成交，持仓是快照。重复导入须幂等，保留券商 ID、币种、时间戳与来源。
- 宣称集成可用前，验证真实账户可访问性、历史覆盖范围和行情权限。

## Wheel 记账

- 一个 cycle 关联卖出 put、指派接股、covered call 与最终平仓；滚仓保留完整交易历史。分组存在歧义时支持显式指定 cycle。
- 区分收到的权利金、已实现盈亏、未实现盈亏和现金变动；协调费用、指派、行权和到期，避免权利金重复计入，并说明成本基础方法。
- 保留币种、时区、合约身份、有符号持仓数量和实际合约乘数。原型乘数 100 只是样例；记账使用适当的十进制精度。

## Greeks 与市场指标

- 聚合前统一供应商 Greeks：符号、每股/每张单位、乘数、Theta 时间基准、Vega 每个波动率百分点单位。显示来源和时间戳，区分行情 Greeks 与模型估计。
- 股数等价 Delta 和 Gamma 按标的分别聚合。组合 dollar Delta 为各标的净 Delta × 现价后换算到共同币种的总和；beta 加权敞口另行标注。Theta 是敏感度，不是保证收入。
- 场景分析说明假设与近似范围。生产指标明确计算变体、输入 bars、交易时段、时区、已收盘/形成中 bar 策略和 Fibonacci 锚点；历史视图避免前视偏差。
- 展示时区分 Setup 与 Countdown、S/R 聚类与贡献的方法/周期，以及用户选定的 Fibonacci 锚点。自定义共振评分不能当作概率，模拟摘要不能声称是实时 AI 分析。

## 验证边界

记账、导入或风险改动按影响选择脱敏样例，独立核对部分成交、重复导入、空头期权、指派、费用、非标准乘数与跨币种结果。已有获授权的券商数据时进行对账。原型只作为设计参考，不视为生产记账或指标引擎。
